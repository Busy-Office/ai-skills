Why this will not become the bottleneck

Budgets degrade, they never hang. A T1 breach falls back to T0's selection, records what was skipped, and pushes it into T2's next batch.
A red gate blocks the commit, not the loop. The item returns to the queue with the failure text; the next tick takes different work. Nothing sits waiting.
The expensive tier is asynchronous. 71 e2e specs never sit on the critical path — only the deploy waits on them.
Deferred work is visible as green debt. The deploy gate refuses to pass with debt older than one cycle — the one place blocking is deliberate.
The gate can shrink. Every run appends a ledger row; the rebalance may demote as well as promote, so the gate gets cheaper as evidence accumulates instead of ratcheting up after every incident.
